- Click **Paper 2** → it jumps to the Paper 2 section.

## 4. Editing on GitHub
For the current static GitHub Pages setup:
1. Open the repository.
2. Click the file you want to change.
3. Click the pencil/Edit button.
4. Make the change.
5. Click **Commit changes**.
6. For a new PDF: open the correct folder and use **Add file → Upload files**.
7. Keep the requested structure:
   resources/P1/Q1
   resources/P1/Q2
   resources/P2/Q1
   resources/P2/Q2

## 5. Important
GitHub Pages itself does not provide a secure "admin dashboard" for the live website. A real login-based admin panel needs a CMS/backend. This final version removes the previous JavaScript `fetch()` dependency so the category navigation works directly on GitHub Pages and also works when previewed as local files.
